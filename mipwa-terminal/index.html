Acerca de AprendeX86

Simulador de Sistema Operativo Linux en Arquitectura x86 corriendo nativamente en el navegador. Diseñado como PWA (Progressive Web App) para móviles.

Tecnologías utilizadas:

  • v86 - Emulador x86 a WebAssembly
  • Buildroot - Kernel Linux + Initramfs ultraligero
  • xterm.js - Renderizado avanzado de terminal
  • HTML/CSS/JS - Interfaz estática sin frameworks
  • Service Worker - Caché offline y capacidades PWA
