Acerca de AprendeX86

AprendeX86 es una plataforma interactiva para aprender a dominar el terminal Linux desde el móvil, ejecutando un sistema x86 real emulado en WebAssembly sin necesidad de servidores externos.

Desarrollado para IGS-UBV — Arquitectura de Computadores.
